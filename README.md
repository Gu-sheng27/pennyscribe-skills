# PennyScribe Skills

Open-source agent skills that turn audio into useful work with [PennyScribe](https://pennyscribe.com).

## Skills

- [`repurpose-podcast`](skills/repurpose-podcast): turn public podcast and video links into a readable full transcript, an editable HTML feature, X copy, and exportable Xiaohongshu cards.

Each skill is self-contained under `skills/` and can be copied into a compatible agent's skills directory. Set `PENNYSCRIBE_API_KEY` locally; never commit API keys or cookies.
